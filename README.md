# Disk-Cleaner - Windows 磁盘清理工具

一个用 **PowerShell + WPF** 编写的 Windows 磁盘清理工具。提供图形化界面，让用户自主选择要清理的磁盘和文件类别，确认后将文件**移入回收站**（而非永久删除），并全程警告用户。

---

## 功能特性

- 🖥️ **磁盘选择**：枚举所有可用磁盘，显示每个磁盘的容量和可用空间
- 📁 **类别选择**：多选清理类别（下载文件、图片、文档、视频、临时文件、回收站、缩略图缓存）
- 🔍 **扫描预览**：扫描所选类别，显示文件列表（文件名、大小、路径、修改时间、类别）
- 🗑️ **回收站清理**：将用户选中的文件移入回收站（**可恢复**，不会永久删除）
- ⚠️ **双重确认**：清理前弹出警告对话框，显示文件数量和总大小，用户必须明确确认
- 📋 **操作日志**：记录所有操作到 `logs/cleaner-log.csv`

## 部署方法

### 1. 下载/复制项目

将整个 `Disk-Cleaner` 文件夹复制到你的电脑任意位置（如 `D:\Tools\Disk-Cleaner`）。

### 2. 运行程序

双击 `DiskCleaner.ps1`，或在 PowerShell 中运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\DiskCleaner.ps1
```

> **注意**：如果直接双击 `.ps1` 文件无法运行，可能是系统默认用记事本打开。请使用上述 PowerShell 命令运行。

### 3. （可选）创建桌面快捷方式

1. 右键点击桌面 → 新建 → 快捷方式
2. 在"位置"中输入：
   ```
   powershell.exe -ExecutionPolicy Bypass -WindowStyle Hidden -File "D:\Tools\Disk-Cleaner\DiskCleaner.ps1"
   ```
3. 点击"下一步"，命名为 "Disk-Cleaner"，点击"完成"

## 使用方法

### 第 1 步：选择磁盘

在左侧"选择磁盘"列表中点击要清理的磁盘（如 `C:`）。

### 第 2 步：选择清理类别

在右侧"选择清理类别"中勾选要清理的类别：

- ☑️ **下载文件**：清理 `Downloads` 文件夹中的文件
- ☑️ **图片**：清理 `Pictures` 文件夹中的图片（jpg/png/gif 等）
- ☑️ **文档**：清理 `Documents` 文件夹中的文档（pdf/docx/xlsx 等）
- ☑️ **视频**：清理 `Videos` 文件夹中的视频（mp4/avi/mkv 等）
- ☑️ **临时文件**：清理系统临时目录中的临时文件
- ☑️ **回收站**：清空回收站（⚠️ 不可恢复，见下方注意事项）
- ☑️ **缩略图缓存**：清理缩略图缓存（thumbcache 文件）

### 第 3 步：扫描

点击 **"🔍 扫描"** 按钮。程序会扫描所选类别，在下方表格中显示可清理的文件列表。

### 第 4 步：选择文件

在文件列表表格中，勾选要清理的文件（勾选第一列的复选框），或点击 **"全选文件"**。

### 第 5 步：清理

点击 **"🗑️ 清理选中文件"** 按钮。程序会弹出警告对话框：

```
⚠️ 警告 - 确认清理

您选择了 N 个文件，总大小 X。
此操作将把所选文件移入回收站，可通过回收站恢复。

确定要继续吗？
```

点击 **"是"** 确认清理，文件会移入回收站（可通过回收站恢复）。

点击 **"否"** 取消，程序不会清理任何文件。

### 第 6 步：刷新

点击 **"🔄 刷新"** 按钮重新加载磁盘列表。

## 注意事项（重要）

### ⚠️ 安全警告

1. **程序不会擅自清理**：程序只扫描和展示，绝不自动删除任何文件。所有清理操作都需用户明确确认。
2. **文件移入回收站**：所有清理操作使用 Windows 回收站 API，文件可以**通过回收站恢复**（临时文件和缩略图缓存除外，见下方说明）。
3. **回收站清理不可恢复**：清空回收站类别会把回收站内的文件**永久删除**。Windows 回收站没有"二级回收站"，清空即永久删除。此选项在界面中已标注 ⚠️ 并需额外确认。

### ⚠️ 文件锁定

- **临时文件**：可能被正在运行的程序占用（如安装程序、更新服务），清理时会跳过并记录错误。
- **缩略图缓存**：可能被资源管理器（Explorer）锁定，清理时会跳过并记录错误。

### ⚠️ 测试安全

- 测试脚本 `run-tests.ps1` **只操作 `TestFiles/` 目录**，不会触碰其他文件夹。
- 测试清理的文件可通过回收站恢复。

## 常见问题 (FAQ)

### Q1: 双击 .ps1 文件无法运行？

**A**: 用 PowerShell 命令运行：
```powershell
powershell -ExecutionPolicy Bypass -File .\DiskCleaner.ps1
```

### Q2: 程序提示"找不到界面文件"？

**A**: 确保 `UI\MainWindow.xaml` 文件与 `DiskCleaner.ps1` 在同一目录结构中。不要只复制 `DiskCleaner.ps1`，要复制整个项目文件夹。

### Q3: 清理的文件还能恢复吗？

**A**: 能。除了"回收站"类别（清空回收站不可恢复）和临时文件/缩略图缓存（可能被占用），其他文件都通过回收站恢复。

### Q4: 为什么有些文件清理失败？

**A**: 文件可能被其他程序占用（如正在编辑的文档、正在播放的视频）。程序会跳过这些文件并记录错误，不会中止整个清理操作。

### Q5: 程序需要管理员权限吗？

**A**: 不需要。普通用户即可运行。但清理系统级文件（如 Windows 更新缓存）可能需要管理员权限，本程序不包含此类功能。

### Q6: 如何查看操作日志？

**A**: 打开 `logs\cleaner-log.csv` 文件。日志记录了每次扫描和清理操作的时间、类型和结果。
