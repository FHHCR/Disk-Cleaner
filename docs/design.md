# Disk-Cleaner 设计文档

**日期**: 2026-11-06
**版本**: 1.0

---

## 1. 产品概述

Disk-Cleaner 是一个用 **PowerShell + WPF** 编写的 Windows 磁盘清理工具。它提供图形化界面，让用户自主选择要清理的磁盘和文件类别（下载文件、图片、文档、视频、临时文件、回收站、缩略图缓存），确认后将文件**移入回收站**（而非永久删除），并全程警告用户。

### 核心设计原则

1. **不擅自清理** - 程序只扫描和展示，绝不自动删除任何文件
2. **回收站而非永久删除** - 所有清理操作使用 `Microsoft.VisualBasic.FileIO.FileSystem` 并指定 `RecycleOption.SendToRecycleBin`，文件可恢复
3. **用户确认** - 每次清理前弹出警告确认框，显示要清理的文件数量和总大小
4. **不编造功能** - 只实现明确的功能，不虚构不存在的能力

---

## 2. 目标、非目标与反目标

### 目标

- 提供图形化界面，用户可选择磁盘和清理类别
- 扫描并展示可清理的文件列表（文件名、大小、路径、修改时间）
- 将用户选中的文件移入回收站（可恢复）
- 生成操作日志
- 用户全程自主决定，程序不擅自清理

### 非目标

- 不永久删除文件（不提供 Shift+Delete 等价功能）
- 不清理系统关键文件（如 Windows 目录下的系统组件）
- 不自动执行定时清理
- 不支持命令行非交互模式（仅 GUI 模式）

### 反目标（失败标准）

- 程序在用户未确认的情况下删除任何文件 → **产品失败**
- 文件被永久删除而非移入回收站 → **产品失败**
- 清理了用户未选择的文件类别 → **产品失败**
- 清理了非用户选择的磁盘上的文件 → **产品失败**

## 4. 功能模块

### 4.1 磁盘选择

- 枚举所有可用磁盘（C:、D:、E:...）
- 显示每个磁盘的：盘符、卷标、总容量、已用空间、可用空间
- 用户可选择一个或多个磁盘进行扫描

### 4.2 类别选择

用户可多选以下清理类别：

| 类别 | 默认路径 | 说明 |
|------|----------|------|
| 下载文件 | `$env:USERPROFILE\Downloads` | 用户下载文件夹 |
| 图片 | `$env:USERPROFILE\Pictures` | 用户图片文件夹 |
| 文档 | `$env:USERPROFILE\Documents` | 用户文档文件夹 |
| 视频 | `$env:USERPROFILE\Videos` | 用户视频文件夹 |
| 临时文件 | `$env:TEMP` | Windows 临时目录 |
| 回收站 | 系统回收站 | 使用 Shell API 清空回收站（可恢复？见说明） |
| 缩略图缓存 | `$env:LOCALAPPDATA\Microsoft\Windows\Explorer` | 缩略图缓存（thumbcache_*.db） |

> **关于回收站**：Windows 回收站的清空操作是**不可恢复**的（回收站本身没有"回收站"）。这是一个已知的 Windows 限制。因此，回收站清理选项会标注"不可恢复，请谨慎使用"，并需要**更强确认**（输入"确认"或额外勾选）。这与"程序不擅自清理"原则一致——用户明确选择后才执行。

### 4.3 扫描预览

- 扫描所选类别，显示文件列表
- 文件列表字段：文件名、大小、路径、最后修改时间
- 显示扫描到的文件总数和总大小
- 扫描结果按大小降序排列（方便用户识别大文件）

### 4.4 清理确认

- 弹窗警告，显示：
  - 将要清理的文件数量
  - 将要清理的总大小
  - 明确警告文案："此操作将把所选文件移入回收站。移入回收站的文件可以通过回收站恢复。"
- 用户必须点击"确认清理"才能执行

### 4.5 移入回收站

- 使用 `Microsoft.VisualBasic.FileIO.FileSystem.DeleteFile` / `DeleteDirectory`，指定 `RecycleOption.SendToRecycleBin`
- 逐个处理文件，记录每个文件的操作结果
- 文件在删除过程中被锁定/占用时，跳过并记录错误（不中止整个操作）

### 4.6 操作日志

- 日志格式：CSV
- 日志字段：时间戳、操作类型（扫描/清理）、文件路径、文件大小、结果（成功/失败/跳过）、错误信息
- 日志位置：`Disk-Cleaner/logs/cleaner-log.csv`

## 5. 技术架构

### 5.1 技术栈

- **语言**: PowerShell 5.1+（`powershell.exe`，非 PowerShell 7，以确保兼容 Windows 10/11 内置版本）
- **UI**: WPF（XAML 定义界面，通过 PowerShell 动态加载）
- **回收站操作**: `Microsoft.VisualBasic.FileIO.FileSystem`（`Add-Type -AssemblyName Microsoft.VisualBasic`）
- **磁盘枚举**: `Get-CimInstance Win32_LogicalDisk`
- **文件枚举**: `Get-ChildItem` + 类别过滤

### 5.3 WPF 界面设计

**主窗口布局**（自上而下）：

1. **标题栏**: "Disk-Cleaner - Windows 磁盘清理工具"
2. **磁盘选择区域**: 左侧 ListBox 显示可用磁盘（盘符、卷标、容量、可用空间）
3. **类别选择区域**: 右侧 CheckBox 列表（下载文件、图片、文档、视频、临时文件、回收站、缩略图缓存）
4. **操作按钮**: "扫描"、"清理选中文件"、"刷新"
5. **扫描结果表格**: DataGrid 显示文件列表（文件名、大小、路径、修改时间）
6. **状态栏**: 显示当前状态（"就绪"、"扫描中..."、"正在清理..."等）

**清理确认对话框**：
- 标题: "⚠️ 警告 - 确认清理"
- 内容: "您选择了 N 个文件，总大小 X。此操作将把这些文件移入回收站，可通过回收站恢复。确定要继续吗？"
- 按钮: "确认清理" / "取消"
- 回收站类别额外要求：需勾选"我了解回收站清理不可恢复"

### 5.4 安全设计

1. **默认零删除** - 程序启动时不执行任何清理操作
2. **双重确认** - 清理前弹窗警告，用户必须明确点击"确认清理"
3. **回收站恢复** - 所有删除使用 `RecycleOption.SendToRecycleBin`，文件可恢复（回收站清理选项除外，标注不可恢复）
4. **路径保护** - 清理路径仅限标准 Windows 用户目录，不含系统关键路径
5. **单文件容错** - 单个文件删除失败不中止整个操作，记录错误继续

## 6. 已批准的技术决策

| 决策 | 选择 | 理由 |
|------|------|------|
| UI 技术 | WPF | 现代美观，XAML 声明式，支持数据绑定，代码结构清晰 |
| 清理类别 | 标准类别（7 项） | 覆盖最常见的可清理项目，风险适中 |
| 测试目录 | Disk-Cleaner/TestFiles | 测试只操作项目内文件，不碰其他文件夹 |
| 回收站操作 | 移入回收站（可恢复） | 符合"程序不擅自清理"和安全性原则 |
